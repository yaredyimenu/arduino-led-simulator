# ⚡ Arduino LED Simulator

A web-based simulator that mimics controlling LEDs on an Arduino Uno R3 board.

## 🔧 Features
- Toggle 4 LEDs (Red, Green, Blue, Yellow) ON/OFF
- PWM brightness control (0–255)
- Real-time Serial Monitor output
- Simulates digitalWrite() and analogWrite() functions

## 💡 Concepts Demonstrated
- Digital pin control (HIGH/LOW)
- PWM signal simulation
- State machine logic
- Embedded systems fundamentals
